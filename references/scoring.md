# 匹配评分口径

## 总原则

1. **可解释**:每个分数都能追溯到「岗位要求 X / 你的情况 Y」。
2. **不臆造**:数据缺失就从加权分母里去掉该维度并标注,不做默认假设。
3. **样本驱动**:市场基准来自本次抓取的真实样本,不引用外部/记忆中的均值。

## 四维权重

| 维度 | 权重 | 说明 |
| --- | --- | --- |
| 薪资 | 0.30 | 求职最关注的硬约束 |
| 学历 | 0.20 | 多为硬门槛,但一档内可放宽 |
| 经验 | 0.22 | 可被项目成果部分弥补 |
| 技能 | 0.28 | 最可主动补齐,权重略高 |

总分 = Σ(维度分 × 权重) / Σ(有效维度权重)。有效维度 = 该维度有分。

## 各维度评分

### 薪资(0–96)

| 情况 | 分 | 逻辑 |
| --- | --- | --- |
| 期望 < 岗位下限,比值 > 0.7 | 75 | 期望偏低,可争取更高 |
| 期望 < 岗位下限,比值 ≤ 0.7 | 62 | 明显偏低 |
| 期望在区间内 | 88–96 | 越靠近中上越高 |
| 期望超上限 ≤ 15% | 70 | 可谈 |
| 期望超上限 15–40% | 45 | 命中难 |
| 期望超上限 > 40% | 22 | 基本不匹配 |

期望未填 → 该维度不计分(返回 `None`),不假设。

### 学历(25–95)

| 情况 | 分 |
| --- | --- |
| 满足或超出要求 | 95 |
| 差一档(如要求本科、你是大专) | 55 |
| 差两档以上 | 25 |
| 岗位未标注学历 | 不计分 |

学历档位:`不限 0 < 高中及以下 1 < 大专 2 < 本科 3 < 硕士 4 < 博士 5`。

### 经验(30–92)

| 情况 | 分 |
| --- | --- |
| 落于要求区间 | 92 |
| 低于下限 ≤ 1 年 | 62 |
| 低于下限 > 1 年 | 30 |
| 高于上限 | 72(提示岗位可能偏初级) |
| 未标注经验 | 不计分 |

经验文本解析:「经验不限/无经验/在校」→ (0, ∞);「应届」→ (0,1);
「3-5年」→ (3,5);「5年以上」→ (5,∞);「1年以内」→ (0,1)。

### 技能(35–95)

命中比例 = 命中标签数 / 岗位标签总数。

| 命中比例 | 分 | 等级 |
| --- | --- | --- |
| ≥ 70% | 77–95 | 覆盖良好 |
| 40–70% | 59–77 | 部分覆盖 |
| < 40% | 35–59 | 缺口较大 |

匹配时做大小写归一与子串包含(长度 ≥ 2 才做包含,避免误命中)。
岗位无技能标签 → 不计分。

## 分档

| 总分 | 判断 | 建议动作 |
| --- | --- | --- |
| ≥ 80 | 强匹配 | 优先投递 |
| 65–79 | 较匹配 | 值得投，注意补短板 |
| 50–64 | 一般 | 可投，评估投入产出 |
| < 50 | 弱匹配 | 不建议优先投入 |

## 薪资分位

- 样本 = 本次抓取中**有薪资字段**的岗位
- **所有分位统一建立在「区间中值」序列上**(`(min+max)/2`),不再混用下限序列
  > 历史 BUG:早期版本 p25/p75/p90 取 `salary_min` 序列,而 p50 取中值序列,
  > 两个不同尺度混用会导致 **p75 < p50 的倒挂**。已修正,并加单调性自检。
- `p50` 取中值序列的中位数
- **年薪制岗位**(`14-25万/年`、`20-25万/年`)解析后 ÷12 折算为月薪再入统计
- 单位混用写法(`9千-1.5万`)左右两侧**各自**定单位
- **带薪资岗位 < 5 条时,报告必须写「样本不足」**,不得输出分位结论

## 胜任度评估(方向 3)

回答「我能不能胜任这类岗位」。

```
学历通过率 = 学历达标岗位数 / 总岗位数
经验通过率 = 经验达标岗位数 / 总岗位数
技能覆盖度 = mean(每岗技能命中率)   # 仅统计有技能标签的岗位

综合胜任度 = 学历通过率 × 经验通过率 × 0.65 + 技能覆盖度 × 0.35
```

设计理由:学历与经验是**否决项**(任一不达标通常直接被筛),故用**乘积**体现
「必须同时过」;技能是可以边投边补的**加分项**,故独立加权。

| 综合分 | 分档 | 结论 |
| --- | --- | --- |
| ≥ 80 | 高 | 完全能胜任,可挑岗位 |
| ≥ 62 | 较高 | 基本能胜任,个别硬门槛需规避 |
| ≥ 45 | 中等 | 部分能胜任,需针对性补强 |
| < 45 | 偏低 | 门槛差距明显,建议调整目标或先补短板 |

同时输出**三项全过的岗位数**与**卡点分布**
(学历不足 / 经验不足 / 经验高于要求)。

## 职业规划(方向 3)

### 职级推断

按岗位名里的关键词映射职级:

| 关键词 | 层级 |
| --- | --- |
| 助理/实习/见习/学徒/储备/管培 | 1 入门 |
| 专员/执行/操作/技术员/绘图 | 2 专员 |
| 工程师/主管/主办/组长/班长 | 3 骨干 |
| 高级/资深/senior/项目负责人 | 4 高级 |
| 经理/manager/项目经理/工程经理 | 5 经理 |
| 总监/director/总工/技术负责人 | 6 总监 |
| 副总/总经理/事业部 | 7 高管 |

**样本量保护**:只在「样本量 ≥ 5 的职级」之间给晋升涨幅结论。
若职级与薪资未呈单调关系,则改述为「收入更多取决于项目规模与公司层次」,
不强行给涨幅数字。高职级样本不足时**明说不足**,不编。

### 薪资成长曲线

按经验要求分段(0-1 / 1-3 / 3-5 / 5-10 / 10年+),分别给薪资中位,
标出用户所处段位与下一段位的提升空间。

### 横向方向

按岗位名判断管理线 / 技术线 / 复合型,给各方向岗位数与中位薪资。
转方向建议先「内部转岗」或「相近项目经验」过渡,而非裸转。

### 证书杠杆

从标签里抽取含「建造师/造价师/注册/职称/安全员X本」的资格证书要求及频次。
这类门槛**可主动攻克**,在工程/建筑/医疗等资质敏感行业,投入产出比通常
高于跳槽试错——报告应明确指出这一点。
