# job-market-scout

> 输入「职位 + 城市」，抓取真实在招岗位，告诉你**薪资期望合不合理、你能不能胜任、下一步该怎么走**。

[![CI](https://github.com/nashhuakai1991-lgtm/job-market-scout/actions/workflows/ci.yml/badge.svg)](https://github.com/nashhuakai1991-lgtm/job-market-scout/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

一个招聘市场侦察与求职决策工具。它不做简历投递，也不替你联系 HR —— 它只做一件事：把散落在招聘网站上的真实岗位抓下来，换算成你能读懂、能行动的结论。

---

## 它能解决什么问题

找工作的时候，最难受的往往不是「找不到岗位」，而是这三件事没底：

1. **我开的价合不合理？** —— 网上搜到的薪资数据要么过期，要么是机构编的均值，不知道信谁。
2. **我到底够不够格？** —— 看了几十条 JD，还是说不清自己差在哪、差多少。
3. **接下来往哪走？** —— 是熬年限、考证、还是换个方向，没人给过基于数据的判断。

本工具针对这三点给出答案，且**每一个数字都能追溯到本次真实抓取的岗位**。

## 效果示例

仓库里有一份完整跑通的报告，可直接打开查看：

→ [`examples/北京装修项目经理/report.html`](examples/北京装修项目经理/report.html)（单文件，浏览器双击即可，无需联网）

> **示例说明**：岗位数据为真实抓取（75 个在招岗位，含公司名与薪资），
> 但**求职者档案是虚构的**（大专 / 5 年 / 期望 1.3 万），用于保护提交者个人隐私。
> 岗位信息本身来自公开招聘页面。

该示例的查询条件是：`北京 · 装修项目经理 · 大专 · 5年经验 · 期望月薪 1.3万`，
抓到 **75 个**真实岗位（智联 + 前程无忧双源），报告给出了这些结论：

| 问题 | 报告给出的答案 |
| --- | --- |
| 期望 1.3万合理吗？ | **合理**。市场 25/50/75/90 分位 = 1.0万 / 1.2万 / 1.5万 / 2.2万，可投岗位占比 60% |
| 我能胜任吗？ | **胜任度 34/100（偏低）**。学历通过 58.7%、经验通过 69.3%、三项全过 28/75 |
| 卡在哪？ | **学历不足（31 个岗位）**为主，兼有经验不足 11 个、经验过高 12 个 |
| 该补什么？ | 学历是最大瓶颈；技能侧缺口集中在**一级建造师**、房建/办公建筑类项目经验 |

注意这份示例得出了**偏负面的结论**（胜任度偏低）。这是刻意保留的——
它说明工具不会为了好看而给高分，学历不匹配时就是会告诉你不匹配。

## 快速开始

### 环境

- Python 3.10+
- Playwright（`pip install playwright`），浏览器用自带的 chromium 即可，脚本会自动探测

### 四步跑完一次分析

```bash
# 1. 采集（默认跑 智联招聘 + 前程无忧 两个免登录源）
python scripts/scrape_jobs.py -k "装修项目经理" -k "装饰项目经理" \
  -c 北京 --pages 3 --limit 70 --out ./out

# 2. 匹配分析（填你自己的情况）
python scripts/match_analyze.py -j ./out/jobs.json \
  --degree 本科 --experience 10 --city 北京 --expect 18000 \
  --skills "装饰装修,工程施工,项目管理,成本管理,二级建造师" --out ./out

# 3. 胜任度评估 + 职业规划
python scripts/career_plan.py -j ./out/jobs.json -a ./out/analysis.json --out ./out

# 4. 生成报告
python scripts/make_report.py -a ./out/analysis.json -c ./out/career.json \
  -j ./out/jobs.json --out ./out --title "北京 装修项目经理 岗位分析"
```

产出 `out/report.html`（可直接分享/打印）与 `out/report.md`。

> 抓取失败可直接原样重跑，脚本会断点续跑（已有结果复用）。

## 数据源现状（实测 2026-10）

这是本项目最需要如实说明的部分 —— **能抓的才写能抓，抓不到的直接写抓不到。**

| 数据源 | 访问方式 | 字段完整度 | 状态 |
| --- | --- | --- | --- |
| **智联招聘** | 免登录 | 完整（薪资 / JD / 技能 / 公司） | ✅ 主通道 |
| **前程无忧** | 免登录 | 完整（结构化 JSON，薪资不掩码） | ✅ 主通道 |
| **中国公共招聘网**（人社部） | 免登录 | 有限（岗位名 / 单位 / 薪资档 / 地区） | ✅ 官方补充 |
| BOSS直聘 | 需扫码登录 | 完整 | 🔐 可选 |
| 猎聘 | — | — | ❌ 返回空页，强风控 |
| 脉脉 | — | — | ❌ 强制跳转扫码登录 |
| 领英 | — | — | ❌ 国内网络不可达 |
| 拉勾 | — | — | ❌ 滑动验证码拦截 |
| 各城市人才网 | — | — | ❌ 域名高度不稳定 |
| 公司官网招聘页 | — | — | ❌ SPA 空壳或跳第三方 |

**两点关键技术发现**（决定了实现方式，也解释了为什么有些源不可用）：

1. **智联列表页的薪资是掩码**（显示为 `**-**元`），真实数据在页面注入的
   `window.__INITIAL_STATE__` 里。只解析 DOM 会丢掉全部薪资 —— 这也是很多抓取脚本失败的原因。
2. **前程无忧的岗位卡片带 `sensorsdata` 属性**，内含完整结构化 JSON
   （`jobTitle` / `jobSalary` / `jobArea` / `jobYear` / `jobDegree`），且薪资不掩码。

详见 [`references/platforms.md`](references/platforms.md)。

## 输出什么

报告包含九个部分：

| 章节 | 内容 |
| --- | --- |
| 数据源状态 | 逐源标注：取到了多少、哪些需登录、为什么没取到 |
| 结论摘要 | 样本量、分档、薪资分位 |
| 薪资期望校准 | 25/50/75/90 分位表 + 期望是否合理 + 可投岗位占比 |
| 能力差距 | 高频技能缺口 + 已命中优势 + 补齐路径 |
| 投递策略 | 强/较/一般三档数量 + 建议投递比例 + 简历关键词 |
| **胜任度评估** | 综合分 + 学历/经验通过率 + 三项全过岗位数 + 卡点 |
| **职业规划** | 职级台阶、薪资成长曲线、横向方向、证书杠杆 |
| 城市对比 | 同城不同区域的薪资分布 |
| 岗位明细 | 按匹配度排序，含可点击原始链接与来源标注 |

### 评分口径

**匹配分** = 薪资 30% + 学历 20% + 经验 22% + 技能 28%，
某维度数据缺失时**自动降权**（从分母去掉），不做默认假设。

**胜任度** = 学历通过率 × 经验通过率 × 0.65 + 技能覆盖 × 0.35。
学历与经验是**否决项**（任一不达标通常直接被筛，故用乘积）；
技能是可边投边补的**加分项**（独立加权）。

完整口径见 [`references/scoring.md`](references/scoring.md)。

## 设计原则

这些是我们在踩坑过程中定下的、并且写进了代码的约束：

- **绝不编造薪资**。分位只来自本次抓取样本；样本不足（<5 条带薪资）时明确写
  「样本不足，无法校准」，而不是引用记忆里的市场均值。
- **绝不编造岗位**。抓不到就说抓不到。
- **如实交代数据源边界**。实测不可用的源，直说不可行及原因，不假装抓到了。
- **登录必须用户同意**。不擅自使用用户账号登录；未纳入分析的登录源要写清楚。
- **小样本不给结论**。职级、成长曲线等推断，样本不足时明说不足。
  职级档位样本 < 3 会标记「偏少」并排除出结论。
- **控制抓取频率**。脚本内置页间与站间 sleep。**不要**为提速而加并发 —— 会直接触发风控导致整批失败。

## 合规与免责

- 本工具**仅用于个人求职研究与市场调研**，不代投递、不批量联系招聘方、不存储任何个人身份信息以外的敏感数据。
- 抓取的是招聘页面**公开可见**的岗位信息，且已做频率控制。请遵守目标站点的
  `robots.txt` 与服务条款；如需商用或大规模采集，请先取得授权。
- 部分站点需要登录才能访问，工具会**询问用户是否登录**，不会擅自使用账号。
- 所有数据为**一次抓取的快照**，岗位可能已下架或调整，投递前请以站点实时信息为准。
- 薪资分位仅代表本次采集样本，不等同于全市场水平；报告不构成任何录用承诺。

## 常见问题

**Q：为什么我只抓到智联和前程无忧的数据？**
A：其余站点实测不可达（见上表）。这是目标站点风控策略的结果，不是脚本 bug。
需要 BOSS直聘数据时可执行 `python scripts/scrape_jobs.py --login --site zhipin` 扫码。

**Q：抓取返回 0 条怎么办？**
A：先看日志里的「各数据源状态」，再按 [`references/troubleshooting.md`](references/troubleshooting.md) 排查。
最常见的原因是页面改版（把新选择器补到 `card_candidates` 最前面）或渲染延迟（前程无忧首帧常是空壳）。

**Q：薪资单位为什么会不一样？**
A：源站写法不统一（`1.5-1.8万` / `8000-16000元` / `9千-1.5万` / `14-25万/年`）。
脚本会分别处理，**年薪会自动 ÷12 折算为月薪**后再进入统计。
